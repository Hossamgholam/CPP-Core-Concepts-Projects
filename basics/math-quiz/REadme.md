# Math Quiz Game – C++ Console Application

A console-based math quiz game written in C++.
The program generates random math questions and evaluates the user’s answers
based on selected difficulty and operation type.

---

## 🎯 Project Purpose
This project was created to practice core C++ programming concepts such as:
- Enums and structs
- Functions and control flow
- Random number generation
- User input validation
- Console-based application design

---

## 🕹️ Features
- Choose number of questions (up to 10)
- Select difficulty level:
  - Easy
  - Medium
  - Hard
  - Mixed
- Select operation type:
  - Addition
  - Subtraction
  - Multiplication
  - Division
  - Mixed
- Randomly generated questions
- Instant feedback for each answer
- Final result summary (pass / fail)

---

## 🛠️ Technologies Used
- C++
- Console Application
- Visual Studio

---



## 🧠 Concepts Practiced
- `enum` for difficulty levels and operations
- `struct` to store questions and quiz results
- Functions for modular program design
- Loops and conditional statements
- Randomization using `rand()` and `time()`
