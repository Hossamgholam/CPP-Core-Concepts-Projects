# 🏦 Bank Management System – Extension 2 (Procedural C++)

This project is the **second extension** of the Bank Management System,
implemented using **procedural programming in C++**.

It builds on Extension 1 by adding **transaction operations** and improving
data handling and user interaction.

---

## 📌 Features

### 🔹 Client Management
- Add new clients
- View all clients
- Find client by account number
- Update client information
- Delete client records

### 🔹 Transactions
- Deposit money
- Withdraw money (with balance validation)
- View total balances of all clients

---

## 🧠 Concepts Used

This extension focuses on strengthening **core C++ fundamentals**, including:

- Procedural programming
- `struct` and `enum`
- File handling (`fstream`)
- Vector-based data storage
- String parsing and formatting
- Console menu systems
- Input validation
- Transaction logic (deposit / withdraw)

---

## 📂 Data Storage

- Client data is stored in a text file:
  ```
  myfill.txt
  ```
- Records use a custom delimiter:
  ```
  #//#
  ```
