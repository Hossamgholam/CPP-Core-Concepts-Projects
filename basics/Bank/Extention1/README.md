# 🏦 Bank Management System – Extension 1 (Procedural C++)

This project is a **console-based Bank Management System** implemented in **C++ using procedural programming**.  
It represents the **first extension** of a larger bank system project, focusing on **core programming fundamentals** before moving to OOP.

---

## 📌 Features

- Add new bank clients
- View all clients
- Search for a client by account number
- Update client information
- Delete client records
- Store and retrieve client data from a text file

---

## 🧠 Concepts Used

This extension focuses on **fundamental C++ concepts**, including:

- Procedural programming
- `struct` for data modeling
- File handling (`fstream`)
- Vectors (`std::vector`)
- String manipulation
- Console menus & user interaction
- Data persistence using text files
